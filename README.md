# 영문공시 대상 모니터 (kind-watch)

KIND '오늘의 공시'를 **30분마다 자동으로** 읽어, 영문번역 서비스 신청 기업이 낸 의무공시 대상만 골라 웹페이지에 보여 줍니다.
기존 Streamlit 앱(english-kospi)과 달리 엑셀 다운로드·업로드도, AI 링크 검색도 필요 없습니다. KIND 목록에 접수번호가 들어 있어 공시 링크를 바로 만듭니다.

## 판정 규칙 (기존 앱과 동일)
1. KIND 회사코드가 `config/kospi_company.csv`(또는 `kosdaq_company.csv`)에 있을 것
2. 공시제목에 `config/*_format.csv`의 서식명 중 하나가 포함될 것 ([정정] 등 머리말과 괄호 꼬리는 그대로 매칭)
3. 제목이 `추가상장`·`변경상장`으로 시작하면 제외
4. 제목에 `종속회사의 주요경영사항`이 있으면 제외

달라진 점은 하나입니다. 서식명과 제목을 비교할 때 **띄어쓰기를 무시**합니다. 서식 목록에는 `현금ㆍ현물 배당 결정`처럼 띄어 써 있는데 KIND 제목은 `현금ㆍ현물배당결정`이라서, 기존 방식으로는 이런 공시가 빠졌습니다.

## 구성
```
kind_watch.py                 조회·판정·저장 스크립트
config/kospi_company.csv      대상 법인 (회사코드, 회사명 …)
config/kospi_format.csv       대상 서식 (서식명 …)
config/kosdaq_*.csv           코스닥 기준자료 (넣으면 자동으로 함께 판정)
docs/index.html               결과 화면
docs/data/results.json        오늘 공시 목록 (자정마다 비워짐)
docs/data/archive/            전날까지의 누적 기록 (월별 YYYY-MM.json, 약 2년 보관)
.github/workflows/watch.yml   30분마다 실행
```

## 설치 (GitHub, 약 10분)
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다 (`.github` 폴더 포함).
2. **Settings → Actions → General → Workflow permissions**를 *Read and write permissions*로 설정합니다.
3. **Settings → Pages**에서 Source는 *Deploy from a branch*, Branch는 `main`, 폴더는 `/docs`로 지정합니다.
4. **Actions** 탭 → *KIND 영문공시 대상 조회* → **Run workflow**로 한 번 실행해 결과가 생기는지 확인합니다.
5. `https://<계정>.github.io/<저장소>/`에 접속하면 결과 화면이 열립니다. 이후 30분마다 자동으로 갱신됩니다.

> GitHub Pages는 무료 계정에서는 **공개 저장소**에서만 열립니다. 대상 법인 목록을 공개하기 어렵다면 저장소를 비공개로 두고,
> 아래 '사내 PC에서 실행' 방식을 쓰거나 유료(Pro/Team) 계정의 비공개 Pages를 이용하세요.

## 사내 PC에서 실행 (GitHub 없이)
```
pip install -r requirements.txt
python kind_watch.py --loop          # 30분마다 조회, Ctrl+C로 중지
python -m http.server -d docs 8000   # 다른 창에서 실행 → http://localhost:8000
```
작업 스케줄러에 `python kind_watch.py`를 30분 간격으로 등록해도 됩니다.

## 화면 사용
- **오늘** 탭: 그날(KST) 공시만 쌓입니다. 24시가 지나면 비워지고 다음 날 목록이 새로 쌓입니다.
  자정 이후 첫 조회 때 전날 목록이 보관함으로 옮겨지며, 00~02시 조회에서는 전날 늦게 올라온 공시도 한 번 더 확인해 전날 기록에 넣습니다.
- **이전 기록** 탭: 월·날짜를 골라 지난 기록을 보고, 목록 복사나 CSV 다운로드를 할 수 있습니다.
- 날짜·시장·검색어로 거를 수 있고, 마지막 조회에서 새로 잡힌 공시에는 **NEW** 표시가 붙습니다.
- **복사** / **미전달 목록 복사**: `[회사명] 공시제목 (일시)` + 링크 형식으로 복사합니다. 네이버 전달용 메일에 바로 붙여 넣으면 됩니다.
- **전달** 체크는 지금 쓰는 브라우저에만 저장됩니다. 다른 PC나 다른 담당자와는 공유되지 않습니다.
- 상단 상태줄에 마지막 조회 시각과 성공·실패 여부가 표시됩니다.

## 기준자료 갱신
`config/*.csv`를 같은 열 이름(회사코드·회사명 / 서식명)으로 교체해 커밋하면 다음 조회부터 반영됩니다.
회사코드는 KIND 5자리 회사코드입니다(예: `9181` → `09181`, 앞자리 0은 자동으로 채움).

## 참고
- GitHub 예약 실행은 혼잡할 때 수 분에서 수십 분까지 늦어질 수 있습니다. 정시에 반드시 확인해야 한다면 사내 PC 방식이 더 안정적입니다.
- 해외(GitHub 서버) IP에서 KIND 접속이 막히면 상태줄에 '조회 실패'가 뜹니다. 그런 경우 사내 PC 방식으로 돌리세요.
